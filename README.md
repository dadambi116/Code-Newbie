# Algorithm study
---

## 📅 1개월차: 기초 + 핵심 유형 다지기
- **목표**: 브론즈~실버 문제 완전 정복, 필수 자료구조/알고리즘 익히기
- **학습 주제**
  - 1주차: 시간복잡도, 구현, 배열/문자열, 정렬(퀵/머지/기본 sort)
  - 2주차: 스택, 큐, 덱, 해시, 우선순위 큐(힙)
  - 3주차: DFS/BFS (그래프 탐색, 미로 탐색, 섬 개수 세기 등)
  - 4주차: 완전탐색, 백트래킹 (순열/조합, N-Queen, 부분집합)
- **추천 문제 사이트**: 백준(실버), 프로그래머스 LV1~2
- **풀이 목표**: 하루 2문제, 주말엔 복습 + 오답 정리

---

## 📅 2개월차: 중급 유형 집중 훈련
- **목표**: 골드 문제 적응, 핵심 알고리즘 숙달
- **학습 주제**
  - 1주차: 탐욕법(Greedy), 이분 탐색(파라메트릭 서치, 입국심사)
  - 2주차: 동적계획법(DP) 기초 → 점화식 세우기, LIS, Knapsack
  - 3주차: 그래프 심화 (다익스트라, 플로이드-워셜, 최소 신장 트리)
  - 4주차: 고급 구현 (시뮬레이션, 삼성 SW 기출 유형)
- **추천 문제 사이트**: 백준(골드), 프로그래머스 LV2~3
- **풀이 목표**: 하루 2~3문제, 주말엔 모의고사(2시간 안에 3~4문제)

---

## 📅 3개월차: 실전 모의고사 + 약점 보완
- **목표**: 코테 환경 적응, 문제 풀이 속도 & 정확도 강화
- **학습 주제**
  - 1주차: 문자열 알고리즘 (KMP, Trie, 라빈-카프)
  - 2주차: 세그먼트 트리, 펜윅 트리(Fenwick Tree), 고급 DP(비트마스크, 구간 DP)
  - 3주차: 기업 코테 기출 (삼성, 카카오, 네이버, 라인 등)
  - 4주차: 실전 모의고사 (주 2회, 시간 재고 연습)
- **추천 문제 사이트**: 프로그래머스 모의고사, 백준 플래 기출, LeetCode Medium/Hard
- **풀이 목표**: 실전 모드 훈련 (IDE 최소화, 실제 환경과 동일하게 연습)
